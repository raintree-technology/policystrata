# Submission Conflict Matrix

Last updated: 2026-06-29

## Safe In Parallel

These can run while SPLASH/ISSTA is under review:

- AI Expo practitioner talk.
- ODSC-style practitioner talk proposals, if used later.
- ISSRE non-proceedings tool/demo submission due 2026-08-15.
- REALM non-archival short paper or presentation.
- POVC presentation or tool demo, if submitted explicitly as a presentation rather than a proceedings paper.
- Public release posts, website pages, repo releases, and YouTube demos, unless a future double-blind venue requires a separate anonymous artifact.

## Requires Separation Or Exclusivity

These should not be submitted with substantially similar text, claims, and figures while another
archival/proceedings version is under review:

- SECUTE archival tool/data paper.
- AgenticDev archival demo/tool paper.
- MAS-GAIN archival short/tool paper.
- TRUST archival short paper.
- RASE archival short/demo paper.
- AISec archival benchmark/security paper.
- DAI archival research paper.

## Recommended Default

- Current decision: Path A public preprint/release first; SECUTE is paused.
- Use AgenticDev, TRUST, RASE, and MAS-GAIN only as backups or materially distinct variants after
  rechecking overlap with the public arXiv preprint.
- Use REALM non-archival and POVC presentation for parallel exposure.
- Hold AISec and DAI until PolicyStrata has a stronger adversarial evaluation and at least one more distinct integration story.
