# PolicyStrata Submission Workspace

Each directory in this folder is a separate venue product. Do not edit the frozen SPLASH/ISSTA
submission packet under `conference-kit/submitted/`.

## Directory Convention

- `submission-fields.md`: fields to paste into a submission portal.
- `paper-outline.md`: paper-specific structure and claim boundaries.
- `readiness.md`: remaining work, checks, and blockers.
- `*.tex` / `*.pdf`: generated paper or abstract files when a venue needs a formal PDF.

## Required Checks Before Upload

1. Verify venue deadline and URL on the official site.
2. Check whether the product is archival/proceedings or non-archival.
3. Check anonymity requirements.
4. Generate the final PDF or proposal file.
5. Run a visual PDF check when applicable.
6. Compute SHA256 and update `../submission-ledger.md`.
7. Record whether the submission conflicts with any active under-review proceedings paper.
