# Reusable PolicyStrata Positioning

## Base Claim

PolicyStrata tests whether governed LLM data-agent stacks preserve policy obligations as requests
move across model-visible tools, validators, compilers, database policies, lineage, and release
filters. It produces deterministic witnesses, CI gates, and reproducible benchmark evidence for
cross-layer policy drift failures.

## Claim Boundary

- Deterministic suite result: 1720/1720 covered injected non-equivalent faults killed, 80 clean controls, 0 false positives.
- This is artifact-suite coverage over implemented operators and fixtures.
- It is not production recall.
- It is not an authorization boundary.
- It is not legal review of privacy policies or terms of service.

## Venue-Specific First Sentences

- Reliability: `PolicyStrata is a reliability-regression tool for governed LLM data agents.`
- Security testing: `PolicyStrata is a software-security testing tool for cross-layer authorization and release-policy drift.`
- Agentic software engineering: `PolicyStrata tests policy-bearing workflows in LLM agents that use private structured-data tools.`
- Governance: `PolicyStrata produces auditable evidence that policy obligations survive autonomous data-agent pipelines.`
- PromptOps: `PolicyStrata turns prompt and tool-manifest drift into a reproducible CI check.`
- Practitioner: `LLM data agents can pass local checks and still release the wrong data; PolicyStrata catches those cross-layer failures before deployment.`
