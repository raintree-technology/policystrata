\begin{abstract}
LLM data agents can pass model, compiler, database, and release-layer checks independently while the composed workflow violates tenant scope, semantic meaning, or release policy. PolicyStrata is a deterministic reliability-regression and stack-audit tool for governed data-agent deployments. It checks whether authorization, semantic, lineage, version, and release obligations survive translation across model-visible manifests, semantic validators, SQL lowerings, database policy/RLS, and release filters. The tool emits minimized witnesses that identify the first violated transition and includes a doctor mode that reports which real stack surfaces are wired: SQL traces, dbt semantic files, PostgreSQL schema/RLS metadata, privacy policies, terms of service, prompt/tool manifests, source maps, release coverage, and CI gates.
\end{abstract}

\section{Industrial Reliability Problem}

Production data agents are composed systems. A model-visible manifest, semantic validator, SQL compiler, database role, row-level security policy, lineage tracker, and release filter may be owned by different teams and updated on different schedules. Local checks can therefore pass while a request crosses a boundary with a stale tenant key, changed metric definition, missing purpose constraint, or release rule that no longer matches the upstream policy.

PolicyStrata treats those failures as reliability regressions across policy-bearing surfaces. It decomposes a deployment policy into authorization, semantic, and release specifications; assigns responsibility-scoped obligations to each surface; and tests transitions rather than only final answers. When a check fails, the tool records a witness with the principal, request, version vector, semantic plan, lowered query, database rows, lineage, observed result, first violated transition, and obligation.

\section{Tool And Evidence}

The reviewer-facing path is deterministic and does not require an LLM API key:

\begin{small}
\begin{verbatim}
uv run pytest
uv run ruff check .
uv run mypy src
POLICYSTRATA_RUN_ROOT=/tmp/policystrata-final-submit \
  ./scripts/reproduce-final.sh
uv run policystrata doctor --config \
  examples/postgres_dbt/policystrata_real_db_clean.yaml \
  --format markdown --out runs/doctor.md
\end{verbatim}
\end{small}

In deterministic artifact suites, PolicyStrata reports witnesses for 1720/1720 covered non-equivalent injected faults with 0 false positives over 80 clean controls. These are artifact-suite coverage results over implemented operators and fixtures, not production recall and not an authorization-boundary claim.

PolicyStrata also includes a brownfield wiring check over BetterOff, a household-finance application fixture using synthetic data. That check exercises real application surfaces: policy and terms documents, prompt manifest, source map, semantic model, SQL/tool traces, Docker PostgreSQL RLS fixture, and CI workflow. The current smoke result is CI gate pass, 0 findings, `ci-gate-ready`, 7 imported-trace checks, and 4 real database checks. The purpose of this case is integration feasibility and CI shape, not fault-discovery measurement.

\section{Demo}

The demo shows a tenant-scoped analytics request, injects a stale compiler/tenant-key mutation, inspects the minimized witness, and then runs `policystrata doctor --config` to show stack wiring, privacy and terms coverage, prompt-manifest drift, source-map coverage, release coverage, and remediation todos. The output is intended for engineering teams that need repeatable evidence that governed data-agent obligations survive deployment changes.
