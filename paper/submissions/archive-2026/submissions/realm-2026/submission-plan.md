# REALM @ EMNLP 2026 Submission Plan

Official page: https://realm-workshop.github.io/call_for_papers/

Deadline: 2026-07-17.

## Recommended Product

Non-archival short paper. REALM explicitly allows non-archival submissions for work under review
elsewhere, so this is the safe parallel path if SECUTE is active.

## Framing

PolicyStrata is an evaluation artifact for LLM agents that use private structured-data tools. The
paper should reduce software-engineering jargon and focus on:

- tool-use reliability;
- private data access;
- agent quality evaluation;
- safety/security/robustness;
- governance of agentic LLM systems.

## Required Text Changes

- Use `language agents` and `tool-using agents` more than `software engineering`.
- Explain policy drift through one agent request and tool manifest.
- Keep deterministic evaluation prominent.
- Avoid claiming general agent safety.

## Conflict Rule

Submit as non-archival if any SECUTE/AgenticDev/RASE/TRUST proceedings submission is active.
